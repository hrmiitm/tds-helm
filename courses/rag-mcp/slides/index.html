03 · INTERVIEW DEEP DIVE08 / 43

Why not simply store “cat = 1, dog = 2”?

Hand-made single label

cat → 1   dog → 2   car → 3

Numeric gaps here are arbitrary: car may be as near to dog as dog is to cat, despite no learned meaning.

One scalar also struggles to represent several relationships at once.

Learned representation

cat → [0.18, −0.44, …]

Training makes many continuous coordinates jointly encode features useful to the objective: meaning, usage, structure and context.

No single axis has to mean “catness”. The *whole pattern* matters.

Dimensionality is a capacity / efficiency choice, not a magic quality score. Test a model and its dimension on real retrieval questions.

How do we show a 6D or 768D cloud?

Xₙ×d → PCA → Zₙ×3

What PCA does not do

It does not decode the meaning of each model dimension.

It does not guarantee all pairwise distances are preserved.

It does not train a new multimodal model.

04 · FORMULA18 / 43

Cosine similarity measures direction

cos(q,x) = (q·x) / (‖q‖‖x‖)

Values lie in [−1, 1] for real, nonzero vectors. Larger = more aligned.

q = [1,0], a = [2,0] → cos = 1.

q = [1,0], b = [1,1] → cos ≈ 0.707.

Watch out

Cosine is undefined for zero vectors.

Multiplying one vector by a positive constant keeps cosine unchanged.

04 · FORMULA19 / 43

Dot product rewards alignment and length

q · x = Σᵢ qᵢ × xᵢ

Larger = stronger inner product.

q = [1,0], a = [2,0] → 2.

q = [1,0], b = [1,1] → 1.

Scale changes ranking

Large-norm vectors can outrank equally aligned short vectors.

For unit vectors, dot product = cosine similarity.

04 · FORMULA20 / 43

Squared Euclidean (L2) measures separation

d²(q,x) = Σᵢ (qᵢ − xᵢ)²

Smaller = closer.

q = [1,0], a = [2,0] → 1.

q = [1,0], b = [1,1] → 1.

Chroma names

Chroma l2 means squared Euclidean distance, not √(sum of squares).

Cosine configuration returns cosine distance: 1 − cosine similarity.

04 · NORMALIZATION23 / 43

A useful identity for normalized vectors

‖q̂ − x̂‖² = 2 − 2 cos(q, x)

If both vectors have norm 1, cosine ranking and squared L2 ranking agree.

Not a blanket claim for unnormalized embeddings.

Unit vectors

cos(q,x) ↑ ⇔ squared L2(q,x) ↓

Non-unit vectors

Magnitudes affect dot and squared distance.

Two knobs change the speed–recall trade-off

M

ef_construction

Construction search breadth. More work may improve graph quality.

ef_search

Search-time candidate breadth. Usually higher recall vs more work.

HNSW is an approximate-neighbor index. Never promise exact recall or a universal speedup.
