# Foundations of RAG & Vector Databases

Welcome to your hands-on learning workspace!

## Directory Layout
- `notebooks/` — Pedagogical interactive JupyterLab notebooks:
  - `00_environment_and_workspace_setup.ipynb` — Environment health & directory topology
  - `01_embeddings_similarity_and_indexing.ipynb` — Multimodal dense embeddings, similarity math & HNSW graphs
  - `02_chromadb_setup_ingestion_retrieval.ipynb` — ChromaDB collection setup, data ingestion & retrieval
- `mini_rag_project/` — Minimal production Python RAG system (`ingest.py`, `retriever.py`, `generator.py`, `main.py`)
- `labs/` — CLI lab scripts and answer verification tools
- `data/` — Knowledge documents, sample inputs, and persistent ChromaDB storage

Follow the guided tasks in the left pane or explore directly in VS Code and JupyterLab.
